# Corner Grocer C++ Application

A C++ application that analyzes grocery purchase data and helps users view how often individual items were purchased.

## Project Overview

This project was developed to process grocery transaction data and provide useful purchase-frequency information. The application reads item data from a file, counts how often each item appears, and allows users to search for specific items or view all purchase frequencies.

## Features

- Search for the purchase frequency of a specific item
- Display all items and their purchase frequencies
- Generate a text-based histogram
- Read and process grocery purchase data from a file
- Create a backup frequency data file
- Validate user menu input

## Technologies

- C++
- File I/O
- Maps
- Functions
- Input Validation
- Object-Oriented Programming
- Data Processing
